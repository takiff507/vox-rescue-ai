Separate third-party requirement: Vox Rescue does not bundle a virtual audio driver. Install the standard VB-CABLE from VB-Audio Software, restart Windows, then use CABLE Output as your microphone. VB-CABLE is donationware. View licensing and donation information.

What you will need

A Windows PC

Use a compatible 64-bit Windows computer with a microphone input.

An audio input

Connect the microphone or audio interface you want to use for calls and recordings.

An output device

Use headphones or speakers for optional return monitoring.

Standard VB-CABLE

Install it separately from the official VB-Audio page and restart Windows.

CABLE Output selected

Choose CABLE Output as the microphone in the Windows application you want to use.
