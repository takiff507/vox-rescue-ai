INTRODUCTION & GUIDE

A clearer voice,
where you need it.

Vox Rescue reduces microphone background noise in real time. Keep your compact control panel open or use the tray while you talk, play or create.

Start with your own microphone

Open VoxRescue.exe. In Microphone, choose your physical microphone. Choose your headphones under Headphones / return. Wait for the engine to load, then enable AI enhancement.

Enable Hear my return to check the processed sound through headphones. Switch return off after checking if you do not want to hear yourself. Return monitoring works without a virtual audio driver.

Use your voice in other apps

Other apps need a Windows microphone endpoint to receive processed audio. The current route uses standard VB-CABLE, third-party donationware by VB-Audio Software, installed separately. It is not included with Vox Rescue.

  1. Get standard VB-CABLE from the official VB-Audio website. Extract the download and run its installer with administrator permission. Restart Windows as instructed by its publisher.
  2. Reopen Vox Rescue or press Refresh. Keep your physical microphone selected as the input. The footer shows Microphone ready when a compatible virtual route is detected.
  3. In the receiving app, select CABLE Output (VB-Audio Virtual Cable) as the microphone. Leave the receiving app's speaker/output on your real headphones.
  4. Run that app's microphone test or make a short test recording. Keep Vox Rescue running while you use the route.
The signal path

Your physical microphone → Vox Rescue enhancement → CABLE Input → CABLE Output → your app.

Vox Rescue sends audio to CABLE Input; other apps listen to CABLE Output.

Discord & meetings

Discord

Open User Settings → Voice & Video. Set Input Device to CABLE Output and Output Device to your headphones. Run the Mic Test before joining a voice channel. Discord input-device help.

Microsoft Teams

Open Settings → Devices and choose CABLE Output under Microphone. Keep Speaker on your real headphones. Use a test call when available. Teams device help.

Zoom & browser meetings

Choose CABLE Output in the meeting app's microphone/audio device selector, and keep your headphones as the speaker. In a browser, allow microphone access and check the site's selected input. Run a microphone test before joining. Zoom audio-device help.

Games & voice chat

Open the game's voice/audio settings. If it offers a microphone input selector, choose CABLE Output. Keep game audio on your headphones, then test voice chat or push-to-talk.

If the game only uses the Windows default microphone, manually choose CABLE Output as the Windows default input, then restart the game if needed. Restore your physical microphone as the default when you stop using Vox Rescue. Some games restrict virtual devices or have their own voice processing; compatibility needs checking in that game.

OBS Studio, streams & recordings

In OBS Studio, add an Audio Input Capture source and select CABLE Output. Avoid also capturing the same device globally under Settings → Audio, because duplicate capture can echo or double the volume. Check the mixer and record a short test before going live. OBS audio-source guide.

In other recording apps, select CABLE Output as the recording input when supported. This route enhances your microphone; it does not automatically process game sound, music or other people's voices.

Get the best result

  • Use headphones to avoid speaker feedback, and keep a consistent microphone distance.
  • Check your physical microphone's level. A distorted input cannot be fully repaired by noise reduction.
  • Compare AI enhancement ON and OFF using the same phrase. Turn off additional noise suppression temporarily in the receiving app if double processing makes speech sound unnatural.
  • Keep the input unmuted and select CABLE Output only in the receiving app; selecting it as Vox Rescue's own input can create a loop.

When something is missing

  • No virtual microphone: check that standard VB-CABLE is installed, reboot, then press Refresh.
  • No voice in the other app: keep Vox Rescue running, verify the physical input and CABLE Output selection, and check Windows microphone permissions.
  • You hear yourself twice: turn off Hear my return or the receiving app's input monitoring. In OBS, avoid duplicate capture.
  • Crackles or delays: close heavy background tasks, check audio-device settings and try a short recording with matching 48 kHz formats where supported.

Close, return or exit

Closing the window keeps the audio route running in the notification area when tray support is available. Double-click the tray icon to return. Use Exit in the window or tray menu to stop the application completely.

Vox Rescue is independent of the named applications and VB-Audio Software. Application menus may change. VB-Audio licensing and donation information.
